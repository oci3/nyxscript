# nyxscript (for discord)
nyxscript is an open source privacy-enhancing tool in which includes a message cypher encoder and decoder, AES-GCM files and lets you customize a fake profile (separate from the usual vanilla profile showcase) with a drag-to-position editor.
this tool has been made for userscript manager tools like tampermonkey or violentmonkey.

a more detailed documentation will come soon but for now here are the keybinds:
- right shift = open the ui
- alt + n = toggle on/off message encoder and decoder
